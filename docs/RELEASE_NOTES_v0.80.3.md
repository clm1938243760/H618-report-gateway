# v0.80.3 研发版说明

`v0.80.3`继续扩展Epson ESC/P2 `c8x/c82`严格自动Profile的实证型号，不增加
模糊匹配或未经验证的通用转换。

## 新增验证型号

- Epson L120使用Gutenprint 5.3.4正式PPD分别生成360 dpi和720 dpi完整ESC/P2流，
  大小为759,602字节和3,258,963字节。
- 网关严格自动选择EscaPy `xp410` Profile，K2B转换耗时约36.5秒和128.8秒，
  两者均生成单页A4 PDF。
- 120 dpi逐页渲染确认标题、正文、边框、灰阶和颜色通道相对位置完整；C/M/Y
  色块顶边均位于第260至261行，没有`generic` Profile的分层错位。
- Epson ET-2750通过独立正式PPD生成的360 dpi流与L120对应流字节完全一致，
  均为759,602字节，SHA-256为
  `97333ddead787f3f1809b798b72a9fa0014459da654aa7a896ceacd7d22e6807`。
- `xp410`受控证据现在覆盖XP-440、L120、L310和ET-2750；L120与L310均验证
  360/720 dpi。未验证型号和其他Gutenprint版本仍不能仅凭系列名称自动放行。

## API和网页

- Profile显示名称由具体型号枚举改为“Epson c8x/c82系列”，避免把内部Profile名
  `xp410`误解为只支持XP-410。
- 详情列出XP-440、L120、L310和ET-2750四个已验证型号；打印流分析证据同步显示
  这四个型号。
- 自动匹配规则本身仍要求完整`REMOTE1 PM/SN`字节指纹，文件名和普通ESC/P2命令
  不参与匹配。

## 部署约束

- 本版本继续使用内部研发授权范围内的EscaPy 1.1.0和GhostPDL，不是量产发布版。
- 不重新处理历史PRN，不覆盖现场配置、报告数据或CUPS任务。
- 720 dpi转换约需两分钟且PDF体积约34 MB；以OCR和报告上传为目标时优先360 dpi。
