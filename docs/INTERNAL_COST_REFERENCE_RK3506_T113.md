# 智能报告采集终端内部成品成本参考

**用途：** 项目内部预算和供应商报价合理性判断，不建议随厂家规格书一起发送。  
**基准日期：** 2026-07-16  
**数量：** 100 台小批试产  
**口径：** 成品含税工程估算，不含设计、软件开发、模具、认证和第三方商业授权。

## 1. 当前结论

| 方案 | 设备本体合理区间 | 完整套装合理区间 | 内部控制目标 |
|---|---:|---:|---:|
| RK3506B/J + 512MB + 8GB | 500-570 元/台 | 530-610 元/台 | 本体约 535 元，套装约 570 元 |
| T113-i + 512MB + 8GB | 480-560 元/台 | 510-600 元/台 | 本体约 520 元，套装约 555 元 |

完整套装包含 5V/3A 适配器和 USB 数据线。实际含税价格以供应商正式报价为准。

该区间故意保留约 10%-15% 小批量波动，主要原因是 512MB DDR、8GB eMMC、小尺寸屏幕、Wi-Fi/BT 模组、BGA 贴装、外壳工艺和电源器件在 100 台数量下议价能力有限。

## 2. 估算变化依据

现有成本表中，RK3506 方案的 100 台完整整机基线约为：

- 2GB eMMC、无屏版本：约 419 元/台；
- 8GB eMMC、0.96 英寸 OLED：约 444 元/台；
- 8GB eMMC、1.14 英寸 IPS：约 458 元/台。

本次规格相对旧基线增加：

- Wi-Fi 5 双频与 Bluetooth 组合模组；
- 2 口 USB 2.0 Hub、两个 USB-A、独立限流和过流检测；
- 独立 AUX USB-C 5V/3A 输入；
- AUX 反向阻断 eFuse、授权负载开关、硬件锁存、电源 MUX 和电压检测；
- USB、RJ45、电源和按键的完整 ESD 防护；
- AUX/MODE 双按键和 RGB LED；
- 5V/3A 适配器和线材升级；
- 100 台条件下更完整的烧录、老化和出厂测试。

新增内容预计使设备本体比旧的 `8GB + 小屏`方案增加约 35-75 元未税硬件和制造成本。计入小批波动和增值税后，形成第 1 节区间。

## 3. 供应商报价判断

### 3.1 明显偏低的报价

设备本体低于约 430 元/台时，应重点检查是否删除或替换了：

- 512MB 外部 DDR 或 8GB eMMC；
- 双频 Wi-Fi/蓝牙；
- 第二个 USB-A 或 USB Hub；
- AUX 手动授权电源链和防倒灌；
- RTC、电池、小屏或外壳；
- USB/RJ45/电源 ESD；
- BGA X-Ray、烧录、老化和出厂测试；
- 含税口径。

### 3.2 明显偏高的报价

完整套装高于约 650 元/台时，应要求供应商说明：

- 是否使用核心板 + 载板而不是直接 SoC PCBA；
- 是否把设计费、BSP 适配费、模具费或认证费摊入单价；
- 是否使用工业宽温、高耐久 eMMC 或认证电源；
- 是否因 100 台 MOQ 产生大量剩余物料；
- 是否包含额外售后、备品、运输或软件许可。

### 3.3 RK3506 与 T113-i 差价

两套完整功能方案在 100 台时的合理差价通常不应超过约 20-40 元/台。T113-i SoC 可能更便宜，但 USB Printer BSP、软件迁移和供应链不确定性可能抵消器件差价。

若 T113-i 仅便宜 10-20 元/台，优先选择 RK3506B/J；只有 T113-i 在全部 USB、PCL、功耗和稳定性验收通过后仍有明显成本优势，才值得切换平台。

## 4. 不计入本表的成本

- 原理图、PCB 和结构设计；
- BSP、Printer configfs、HID、屏幕和电源管理适配；
- 业务软件移植；
- 模具；
- EMC、安全、SRRC 和其他认证；
- GhostPDL/Ghostscript 商业授权；
- 医疗行业注册、质量体系和现场实施；
- 云端平台和远程设备管理。

这些项目后续需要单独立项，但不得在本轮 100 台成品单价中重复计算。

## 5. 使用建议

1. 先要求供应商按完整规格分别报价 RK3506 和 T113-i。
2. 第一轮不向供应商提供本内部目标价。
3. 收到报价后逐项核对料号、税率、适配器、线材、包装和测试范围。
4. 对最低价和最高价各选一家进行技术澄清，确认没有删减强制功能。
5. 最终选型不能只看单价，USB Printer 实板验证和禁止 VBUS 倒灌属于一票否决项。
