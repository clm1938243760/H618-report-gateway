**目标数量：** 小批试产 100 台，后续批量数量待定  
**文档版本：** V1.0  
**日期：** 2026-07-16  
**产品代号：** Report Gateway Lite

## 1. 文档说明

### 1.1 需求等级

本文使用以下等级：

- **必须：** 第一版成品必须满足，不允许以降低报价为由删除。
- **目标：** 设计时必须按该指标实现，样机阶段通过实测确认。
- **建议：** 厂家可根据供应链、PCB、结构和成本提出等效替代方案。
- **预留：** 第一版不一定装配，但 PCB、接口或软件架构应保留升级空间。

厂家提出器件、接口或实现方式变更时，必须列出变更原因、成本影响、性能影响和软件适配影响，不得只给出总价。

### 1.2 报价口径

本轮只评估 **100 台小批试产条件下的成品含税单价**，不评估 500 台、1000 台等阶梯价格。

本轮报价不包含以下一次性费用：

- 硬件原理图和 PCB 设计费；
- BSP、驱动和业务软件的一次性开发费；
- 外壳模具费；
- EMC、安全、SRRC、入网等认证费；
- 专利、商用字体和第三方商业软件授权费。

厂家只需给出以下两个成品价格：

1. **设备本体单价：** 已组装、烧录、校准、测试合格并带基础包装的终端，不含外置适配器和数据线。
2. **完整套装单价：** 设备本体 + 5V/3A 适配器 + USB 数据线 + 基础包装。

成品单价必须包含：PCBA、512MB 内存、8GB eMMC、Wi-Fi/蓝牙、RJ45、USB 接口、电源保护、RTC 和电池、约 1 英寸屏幕、按键、指示灯、外壳、装配、烧录、老化和出厂功能测试。

## 2. 产品定义

### 2.1 产品用途

本产品部署在医疗检查设备或普通计算机旁，作为 USB 外设和网络网关使用。它接收主机通过虚拟打印机或虚拟 U 盘产生的报告文件，在本地完成文件识别、必要的 PDF 转换、缓存、审计和网络上传。

设备同时预留 HID 键盘和 HID 鼠标模拟能力，供后续自动录入项目使用。主机端不安装专用客户端，优先使用 Windows、Linux 和其他主流系统原生 USB 类驱动完成免驱枚举。

### 2.2 主要功能

- USB Mass Storage Device（MSC）模拟和文件采集；
- USB Printer Device 模拟和打印数据采集；
- USB HID Keyboard 模拟；
- USB HID Mouse 模拟；
- 四种 USB Gadget 模式切换；
- PCL、PCL XL、PostScript 等打印数据转 PDF；
- PDF、JPEG、PNG、BMP、TXT 文件归一化处理；
- 报告本地缓存、失败重试、审计日志和网络上传；
- 100M 有线网络、Wi-Fi 5 双频无线网络和蓝牙；
- HTTPS 本地管理页面；
- 约 1 英寸本地状态屏、双按键和 RGB 状态灯；
- USB U 盘离线升级；
- 主机 USB 供电和独立旁路 5V 供电；
- 低压检测、旁路电源手动授权和全路径防倒灌。

### 2.3 第一版不包含

- HDMI RX；
- HDMI TX；
- MIPI DSI、LVDS 或 RGB 大屏接口；
- 摄像头接口；
- 触摸屏；
- 4G/5G 蜂窝通信；
- 云端统一设备管理、远程批量配置和远程桌面功能。

后续如需要采集 HDMI 图像，使用外置 USB 2.0 UVC 采集卡，不在主板上集成 HDMI RX。

## 4. 核心平台

### 4.1 首选平台

**必须优先报价：RK3506B 或 RK3506J + 512MB DDR3/DDR3L + 8GB eMMC。**

选择理由：

- 三核 Cortex-A7，能够分担 USB Gadget、文件转换、Web 管理和上传任务；
- 两路 USB 2.0 OTG，便于将 Device/Gadget 与 Host 外设隔离；
- 两路 RMII、UART、SPI、I2C 等接口能够覆盖本产品需求；
- 与现有 Rockchip Linux、configfs 和 USB Gadget 项目经验连续。

不得使用仅集成 64MB/128MB 内存的 RK3506G1/G2 替代完整功能版本。

### 4.2 成本备选平台

**允许等功能报价：T113-i + 512MB DDR3 + 8GB eMMC。**

T113-i 具有双核 Cortex-A7、USB 2.0 DRD、USB 2.0 Host、独立 SDIO、eMMC 5.0 和 EMAC，可作为成本优先方案。不得使用 64MB/128MB/256MB SiP 版本替代 512MB 完整功能方案。

### 4.3 两个平台必须保持等功能

厂家给出 RK3506 和 T113-i 两套方案时，必须保持以下内容一致：

- 512MB 内存；
- 8GB eMMC；
- 四种 USB Gadget 模式；
- 两个 USB-A Host；
- 100M RJ45；
- Wi-Fi 5 双频和蓝牙；
- 约 1 英寸状态屏；
- 双 USB-C 供电和防倒灌；
- RTC、电池、双按键、RGB LED、UART；
- ESD 和电源保护等级；
- 报告格式、性能和可靠性指标。

不得通过取消屏幕、蓝牙、HID、ESD、电源检测或 USB Hub 获得更低的对比报价。

### 4.4 资源配置

| 项目 | 必须规格 | 说明 |
|---|---:|---|
| CPU | RK3506B/J 或 T113-i | 同等级 Linux SoC 替代需书面确认 |
| 内存 | 512MB | 不接受 128MB/256MB 版本 |
| eMMC | 8GB | 建议工业级或高耐久料号 |
| SPI NOR | 预留或 16MB | 可用于引导、恢复或工厂烧录，厂家提出方案 |
| RTC | 独立硬件 RTC | 带 CR1220/CR2032 或等效纽扣电池 |
| 看门狗 | 硬件看门狗 | 系统异常自动恢复 |
| 安全存储 | SoC OTP/唯一 ID | 用于设备唯一编号和升级校验 |

## 5. USB 系统

### 5.1 USB 接口配置

| 接口 | 数量 | 类型 | 用途 |
|---|---:|---|---|
| 主机连接口 | 1 | USB-C, USB 2.0 Device/OTG | 与医疗设备/电脑连接，同时接收主机 5V 供电 |
| USB Host | 2 | USB-A, USB 2.0 High-Speed | U 盘、调试外设或外置 UVC 采集卡 |
| 旁路供电口 | 1 | USB-C, 5V 输入 | 独立 5V/3A 辅助供电，不传输数据 |

USB Device 接口必须采用 USB-C。不得使用 USB-A 母口作为 Device 接口，也不得要求用户使用不规范的 USB-A 对 USB-A 数据线。

### 5.2 四种 Gadget 工作模式

| 模式 | USB 功能组合 | 主要用途 |
|---|---|---|
| 模式 1 | MSC + HID Keyboard + HID Mouse | U 盘报告采集并保留自动录入能力 |
| 模式 2 | Printer + HID Keyboard + HID Mouse | 打印报告采集并保留自动录入能力 |
| 模式 3 | MSC | 只模拟 U 盘，兼容性优先 |
| 模式 4 | Printer | 只模拟打印机，兼容性优先 |

模式切换方式：

- 本机 MODE 按键；
- HTTPS 管理页面；
- 维护命令行接口。

系统应保存最后一次确认的模式，重启后恢复。切换时必须先停止对应采集服务、解绑 UDC、重建 configfs 功能、重新绑定 UDC，再启动新模式服务。失败时自动回滚到上一个可用模式。

不同模式应使用稳定且可追溯的 VID、PID、序列号、Manufacturer 和 Product 字符串。每台设备必须有唯一 USB 序列号，避免 Windows 缓存冲突。

### 5.3 USB Host 拓扑与供电

- SoC 的独立 Host 控制器通过 USB 2.0 Hub 扩展为两个 USB-A。
- 两个 USB-A 均支持 USB 2.0 High-Speed 480Mbps。
- 每个 USB-A 使用独立限流/负载开关，具备过流、短路和热保护。
- 每个 USB-A 均增加低电容 USB 2.0 ESD 防护器件。
- 使用旁路 5V 时，建议单口最大 1A、两口合计最大 1.5A。
- 仅使用主机 OTG 供电时，默认限制或关闭高功率 USB-A 负载，只允许功耗预算内的维护 U 盘工作。
- 其中至少一个 USB-A 必须能在旁路 5V 开启时稳定驱动 USB 2.0 UVC 采集卡。
- 如接移动硬盘或高功率采集卡，用户必须接入并授权 5V/3A 旁路电源。

Wi-Fi/蓝牙优先使用 SDIO + UART 连接，避免占用 USB Host 带宽。若厂家受限于引脚复用而采用 USB Wi-Fi，必须证明在 Wi-Fi 上传和 UVC 采集卡同时工作时 USB 总线稳定，不掉盘、不掉网、不丢帧。

### 5.4 USB 内核要求

Linux 内核至少启用：

```text
CONFIG_USB_GADGET=y
CONFIG_USB_LIBCOMPOSITE=y
CONFIG_USB_CONFIGFS=y
CONFIG_USB_CONFIGFS_MASS_STORAGE=y
CONFIG_USB_CONFIGFS_F_HID=y
CONFIG_USB_CONFIGFS_F_PRINTER=y
CONFIG_USB_PRINTER=y
```

必须存在可用 UDC，且能够同时创建 Printer/MSC 与 HID Keyboard/HID Mouse 的复合设备。USB Printer configfs 功能、`/dev/g_printer0`、`/dev/hidg0` 和 `/dev/hidg1` 必须在目标 BSP 实板验证，不能只依据 Kconfig 判断可用。

### 5.5 MSC 设计

- 默认虚拟磁盘容量：512MB FAT32；
- 使用 eMMC 文件作为 backing file；
- 支持安全卸载、稳定时间判定、增量扫描和文件复制；
- 主机挂载期间，不允许 Linux 直接以读写方式同时挂载同一 backing file；
- 文件复制完成后按文件大小、修改时间和 SHA-256 建立处理记录；
- 产品版本支持去重，测试模式允许关闭去重；
- 支持 PDF、JPEG、PNG、BMP、TXT 和其他配置允许的文件类型。

### 5.6 Printer 设计

- 通过 USB Printer Gadget 接收原始打印任务；
- 支持 PJL/UEL、PCL、PCL XL、PostScript、PDF 和常见图像数据识别；
- 优先使用协议结束符、作业边界或 USB 状态判定作业结束；
- 无明确结束标志时使用可配置空闲超时；
- 原始打印数据先写临时文件，再原子移动到待转换目录；
- 断电或服务重启后必须能够恢复未完成任务，不生成半份正式报告。

## 6. 电源系统

### 6.1 供电方式

设备具有两路 5V 输入：

1. **HOST VBUS：** 来自 USB-C Device/OTG 主机接口，作为默认主电源。
2. **AUX 5V：** 来自独立 USB-C 电源接口，推荐适配器规格 5V/3A。

AUX USB-C 只接收 5V，不要求 USB PD 协议。接口必须清楚标注为 `AUX 5V`，避免与主机数据口混淆。

HOST VBUS 的可用电流取决于主机接口和线材。设备不得默认所有 USB 2.0 主机都能提供 1A 或更高电流：

- USB-C 对 USB-C 连接时，可根据 CC 宣告能力确定允许电流；
- USB-A 对 USB-C 连接且无法获得更高供电能力时，按 USB 2.0 500mA 基线设计保护策略；
- 主机供电能力不足时，设备仍应优先保持 USB Gadget、队列和文件系统安全，并提示接入 AUX；
- 不得为了维持 Wi-Fi、转换或 USB-A 外设而持续过载主机 USB 口。

### 6.2 旁路电源控制逻辑

旁路电源只允许用户手动授权或关闭：

- 默认使用 HOST VBUS；
- 检测到主机电压不足时，状态屏显示低压告警，RGB LED 显示红色告警；
- 用户接入 5V/3A 适配器后，按 AUX 按键授权旁路 5V；
- 用户也可在 HTTPS 管理页面授权或关闭旁路 5V；
- 授权状态必须在屏幕和管理页面清晰显示；
- 用户关闭旁路后，系统回到 HOST VBUS，并立即限制高功率 USB-A 负载；
- 旁路适配器拔出时自动回退 HOST VBUS，不得因切换导致文件损坏；
- 旁路授权状态是否跨重启保存由软件配置决定，默认不跨冷启动保存，避免无人值守时误上电高功率外设。

AUX 输入必须经过独立反向阻断 eFuse 和可控负载开关，再进入电源 MUX。授权信号使用硬件锁存或等效掉电安全电路：

- 冷启动默认关闭 AUX 负载开关，AUX 即使已经插入也不得自动接管；
- AUX 实体按键可以直接置位/复位授权锁存，保证 HOST VBUS 太弱、SoC 尚未完整启动时仍可授权供电；
- HTTPS 操作通过受控 GPIO 或电源管理器置位/复位同一授权锁存；
- 软件重启、进程崩溃和 GPIO 变为高阻时不得产生意外授权；
- 授权后由电源 MUX 自动完成无缝选路；
- 未授权时 AUX 输入必须与系统电源电气隔离，不能仅在软件界面上显示“关闭”。

厂家必须在原理图中明确标出 `AUX_PRESENT`、`AUX_AUTH`、`AUX_POWER_GOOD`、`HOST_VBUS_SENSE` 和 `USB_LOAD_SHED` 等等效信号，以及它们在 SoC 未启动时的默认状态。

### 6.3 电源保护

必须实现：

- HOST VBUS 与已授权 AUX 5V 的双路电源 MUX 或理想二极管选路；
- 两路输入反向电流阻断；
- 任何状态下不得向主机 USB 口倒灌 5V；
- 设备关机、主机断电、AUX 单独接入、两路同时接入时均不得倒灌；
- 输入过压、欠压、过流、短路和反接保护；
- USB-A 端口独立限流和故障上报；
- 5V 主电源及关键 3.3V/1.xV 电源监测；
- 关键电源状态可由 SoC ADC 或专用监控 IC 读取；
- 供电不足时优先关闭 USB-A 高功率负载，保证文件系统和上传队列安全。

建议告警阈值：

- HOST VBUS 低于约 4.75V 持续 500ms：低压告警；
- HOST VBUS 低于约 4.50V：进入负载保护，关闭高功率 USB-A；
- 实际阈值由选定电源芯片、PCB 压降和整机负载测试确定。

低压红色告警应尽可能由硬件电源监控电路驱动，即使 SoC 未能完整启动也能给出提示。

### 6.4 功耗预算

| 负载 | 目标预算 |
|---|---:|
| SoC + DDR + eMMC + PMIC | 2.0-3.5W |
| Ethernet + Wi-Fi/BT | 1.0-2.5W |
| 小屏 + LED + RTC | 小于 0.5W |
| USB-A 外设合计 | 最大约 7.5W |
| 转换峰值和损耗余量 | 1.0-2.0W |
| 整机 AUX 输入上限 | 15W, 5V/3A |

厂家必须提交典型待机、网络上传、PDF 转换和满 USB 负载四种工况的实测电流。

## 7. 网络与无线

### 7.1 有线网络

- 1 个 10/100Mbps RJ45；
- 内置网络变压器，建议带 Link/Activity 指示灯；
- 支持 DHCP 和静态 IP；
- 支持 IPv4，IPv6 为建议项；
- RJ45 差分线增加专用低电容 ESD 防护；
- 网口屏蔽壳接地方案按 EMC 规范处理，避免直接污染数字地。

### 7.2 Wi-Fi

- Wi-Fi 5，802.11a/b/g/n/ac；
- 同时支持 2.4GHz 和 5GHz；
- 1T1R 即可；
- 支持 WPA2-PSK，建议支持 WPA3-SAE；
- 使用内置 PCB 天线；
- 外壳必须采用对射频影响较小的 ABS/PC，天线净空区不得有铜、金属螺柱、屏幕排线或电池遮挡；
- 量产前需完成暗室或至少整机 OTA 对比测试，不能只验证模组裸板信号。

### 7.3 蓝牙

- 支持 Bluetooth 5.0 或以上；
- 经典蓝牙和 BLE 能力按模组实际规格列明；
- 蓝牙第一版不承担关键业务，但硬件和驱动必须可用。

## 8. 屏幕、按键和指示灯

### 8.1 状态屏

- 尺寸：约 0.96-1.14 英寸条形屏；
- 推荐：0.96 英寸 160x80 SPI IPS；
- 接口：SPI，3.3V 逻辑；
- 不使用 MIPI、LVDS 或 HDMI；
- 不需要触摸；
- 亮度支持软件调节或自动熄屏；
- 屏幕模组工作温度必须覆盖 0-50 摄氏度整机范围。

屏幕至少显示：

- 当前 USB 模式；
- HOST VBUS 和 AUX 5V 状态；
- 旁路 5V 是否已授权；
- 有线网络/Wi-Fi 连接状态；
- 本机 IP 地址；
- 待上传和失败报告数量；
- 最近一次上传结果；
- DeviceCode；
- 低压、过流、存储不足、上传失败和升级状态；
- 必要时显示简短错误代码，详细信息在 HTTPS 页面查看。

### 8.2 按键

设备配置两个实体业务按键：

1. **AUX 按键：** 手动授权/关闭旁路 5V。长按 2 秒执行，防止误触。
2. **MODE 按键：** 短按浏览模式，长按 2 秒确认切换；或由软件设计为短按循环并在 3 秒后自动确认。

两个按键均需要硬件或软件去抖，建议 30-80ms。外部按键引线和接口处增加 ESD 防护，不得直接将长走线接入 SoC GPIO。

### 8.3 RGB 状态灯

- 绿色：系统正常；
- 蓝色：网络通信或上传；
- 黄色：等待配置、模式切换或旁路电源待授权；
- 红色：低压、上传失败、存储不足或系统故障；
- 闪烁节奏必须在软件文档中统一定义，避免不同版本含义变化。

## 9. 串口与维护接口

- 1 路 3.3V TTL UART；
- 信号：3V3、TX、RX、GND；
- 不支持 RS-232 电平，不允许接 5V TTL；
- 建议使用机内 4Pin 维护座或防呆接口；
- 默认波特率 115200, 8N1；
- 量产版本可关闭串口登录，仅保留启动日志和受控维护模式。

## 10. 软件系统

### 10.1 操作系统

量产首选 **Buildroot 无桌面 Linux**。Debian 仅作为开发、调试或厂家 BSP 验证镜像。

Buildroot 镜像必须包含：

- Linux USB configfs、Printer、Mass Storage 和 HID 功能；
- Python 3 及当前业务依赖，或经验证的等效 Go/C 控制面；
- SQLite；
- HTTPS Web 服务；
- GhostPDL/GhostPCL、Ghostscript 和图像处理库；
- Wi-Fi、Bluetooth、Ethernet、RTC、看门狗和屏幕驱动；
- USB U 盘离线升级和恢复机制。

第一版优先移植现有 Python 业务，只有 512MB 实板压力测试不通过时才重写控制面。报告转换仍由成熟转换引擎完成，不在本项目中自行实现 PCL 解释器。

### 10.2 软件模块

| Watchdog Agent | 进程与系统健康检查 |

### 10.3 报告处理流程

```text
MSC 文件 / Printer 原始任务
          |
          v
文件稳定与作业结束判定
          |
          v
格式识别与 SHA-256
          |
          v
PDF 直通或 PCL/PS/图像/TXT 转 PDF
          |
          v
PDF 完整性校验 + ReportInfo.xml
          |
          v
SQLite 持久队列
          |
          v
HTTPS/HTTP 上传 -> 成功归档 / 失败重试
```

- 首次登录强制修改默认密码；
- DeviceCode、ExamDoct、ExamDoctCode；
- 上传接口、超时、重试次数和重试间隔；
- MSC/Printer/HID 四种模式切换；
- AUX 5V 手动授权/关闭；
- 有线网络、Wi-Fi 和时间配置；
- 报告队列、上传状态、失败详情和手动重试；

### 10.6 本地数据与容量

业务假设：

- 单份报告最大 2-3MB；
- 每天最多 20 份；
- 断网后至少缓存半天；
- 并发转换数固定为 1。

最低存储规划：

| 分区/目录 | 建议空间 |
|---|---:|
| Boot/Recovery | 256-512MB |
| RootFS A | 1.0-1.5GB |
| RootFS B 或恢复镜像 | 1.0-1.5GB |
| MSC backing image | 512MB |
| 报告、原始任务、数据库和日志 | 不少于 2GB |
| eMMC 预留和磨损余量 | 不少于 15% |

待上传和上传失败报告不得被自动删除。已上传报告默认保留 7 天，可在管理页面配置。日志采用轮转，防止写满 eMMC。

## 11. 离线升级与恢复

### 11.1 USB U 盘升级

- 升级包通过 USB-A U 盘导入；
- 升级包必须包含版本、适用硬件版本、SHA-256 和数字签名；
- 仅接受签名正确且目标硬件匹配的升级包；
- 支持应用升级和完整系统升级；
- 升级前检查剩余空间、电压和旁路电源状态；
- 系统升级时要求接入并授权 AUX 5V；
- 升级过程中屏幕和 RGB LED 显示进度；
- 断电后能够回到旧版本或恢复分区，不得变砖；
- 禁止普通 U 盘文件覆盖系统可执行文件；
- 保存升级审计记录。

8GB eMMC 优先采用 A/B RootFS；若 BSP 空间或引导方案不适合 A/B，厂家必须提供等效的 Recovery 分区和原子应用升级方案。

### 11.2 工厂恢复

- 预留 MaskROM/FEL/USB Download 或等效量产烧录入口；
- 预留串口启动日志；
- 设备序列号、MAC 地址、USB 序列号和 DeviceCode 可在工厂写入；
- 恢复镜像不得覆盖已导出的生产校准数据和唯一编号。

| 低压检测到告警显示 | 不大于 500ms |

### 12.2 报告转换

测试条件：单份输入不超过 3MB、不超过 20 页、单任务转换、使用双方确认的 PCL/PCL XL/PS/图像样本集。

| 项目 | 目标指标 |
|---|---:|

## 13. 安全要求

- HTTPS 管理端口固定为 8443，可由用户导入正式证书；
- 首次登录必须修改随机初始密码；
- 密码使用强哈希保存，不得明文写入配置；
- 管理操作、模式切换、旁路电源授权、升级和报告删除均记录审计日志；
- 禁止 Web 页面直接执行任意 shell 命令；
- 上传接口支持 TLS，证书校验默认开启；
- U 盘升级包必须验签；
- 生产镜像关闭无密码 SSH 和调试后门；
- 唯一设备密钥不得放在可直接下载的 Web 目录；
- RTC 和 NTP 同时使用，断网时依靠 RTC 保持审计时间。

## 14. 结构设计

### 14.1 外形目标

- 暂定最大尺寸：`100 mm x 50 mm x 30 mm`；
- 在满足 RJ45、双 USB-A、双 USB-C、小屏、按键、天线净空和散热的前提下尽量缩小；
- 采用长方形结构；
- 建议 ABS+PC 阻燃塑料外壳；
- 风扇less，被动散热；
- 整机环境温度：0-50 摄氏度；
- 桌面放置，建议预留壁挂孔或扎带固定点。

### 14.2 接口布局原则

- 主机 USB-C 与 AUX 5V USB-C 分开布置并使用不同颜色/丝印；
- 两个 USB-A 留足相邻插头空间；
- RJ45 不遮挡天线；
- 屏幕和两个按键位于正面或顶部，用户可直接操作；
- RGB LED 不得被外壳遮挡；
- UART 和工厂烧录口建议位于机内，拆盖后可访问；
- 外壳开孔处避免形成尖角和薄壁；
- 内置 PCB 天线区域不得使用金属喷涂。

### 14.3 散热

- 正常运行不使用风扇；
- 厂家根据 SoC、PMIC 和 Wi-Fi 模组热测试决定是否增加石墨片、导热垫或小型金属均热片；
- 0-50 摄氏度环境下持续进行转换、Wi-Fi 上传和 USB 满负载时不得降频至影响验收指标；
- 建议 SoC 结温保持低于 85 摄氏度，外壳可触表面不高于 50-55 摄氏度。

## 15. ESD、EMC 和可靠性设计

### 15.1 ESD 防护范围

以下所有可触及接口必须增加 ESD 防护：

- USB-C Device/OTG；
- USB-C AUX 5V；
- 两个 USB-A；
- RJ45；
- AUX 按键和 MODE 按键；
- 调试 UART 如外露；
- 屏幕外露金属件和外壳可触点。

设计目标：

- 接触放电：至少 ±4kV；
- 空气放电：至少 ±8kV；
- USB 2.0 D+/D- 使用低电容 ESD 管；
- 电源输入使用适合 5V 电源线的 TVS、保险或 eFuse；
- RJ45 使用专用阵列和合理机壳地泄放路径。

该指标为产品设计和预一致性测试目标，不等同于本轮包含正式认证费用。

### 15.2 稳定性

- 7x24 小时运行；
- 应用进程异常自动拉起；
- 系统卡死由硬件看门狗复位；
- 所有关键文件使用原子写入；
- SQLite 使用 WAL，事务状态可恢复；
- eMMC 使用只读系统分区或受控写入，数据分区独立；
- 突然断电不得破坏启动分区；
- 主机反复插拔不得造成 UDC 永久失效；
- Wi-Fi/网线切换和网络中断不得丢失报告。

### 16.1 硬件验收

## 18. 技术风险和决策项

### 18.1 USB Printer BSP 风险

SoC 具有 USB OTG 不代表 BSP 已完整支持 Printer configfs。原理图冻结前，必须在候选板上实际创建 Printer + HID 复合设备，并由 Windows 主机完成枚举、打印和 HID 测试。

### 18.2 512MB 内存风险

当前 RK3566 实测表明 Python 服务占用较低，简单 GhostPCL 样本转换也较快，但复杂医疗报告可能显著提高峰值内存。冻结 512MB 量产前必须使用现场 PCL/PCL XL 样本连续压力测试；若出现 OOM，应先精简系统和限制转换并发，再评估是否升级 1GB。

### 18.3 第三方转换引擎授权

GhostPDL/Ghostscript 采用 AGPL 与商业许可双路线。若最终产品为闭源商业分发且不能满足 AGPL 源码公开要求，应单独取得商业许可。该许可费用不计入本轮成品硬件单价，由项目方另行评估。

### 18.4 Wi-Fi 与 USB 带宽风险

优先采用 SDIO Wi-Fi/BT。若采用 USB Wi-Fi，必须在外置 UVC 采集卡、报告上传和 USB U 盘同时工作时验证 Hub 带宽和供电，不能只进行单设备测试。

### 18.5 结构尺寸风险

`100 mm x 50 mm x 30 mm` 同时容纳 RJ45、双 USB-A、双 USB-C、屏幕、按键、天线净空和安全间距较紧。厂家应先给出接口堆叠图和 3D 布局；如确实无法满足，不得缩减接口，应优先提出最小可实现尺寸及具体原因。

## 19. 冻结结论

第一版产品按以下基线评估：

> RK3506B/J 首选、T113-i 备选，512MB DDR、8GB eMMC、100M RJ45、Wi-Fi 5 双频、Bluetooth、USB-C Device/OTG、USB-A x2、独立 USB-C 5V/3A AUX、约 1 英寸 SPI 状态屏、AUX/MODE 双按键、RGB LED、RTC 和纽扣电池；支持 MSC/HID、Printer/HID、MSC、Printer 四种模式，模式可由按键或 HTTPS 页面切换；旁路 5V 只能手动授权/关闭，所有供电状态禁止向主机倒灌；USB、网口、按键和电源接口均需 ESD 防护；第一版不集成 HDMI RX/TX，视频需求使用外置 USB 采集卡；量产系统优先 Buildroot，支持 U 盘签名离线升级。

厂家应基于上述完整功能给出 100 台设备本体和完整套装的成品含税单价，不计入设计、模具、认证和一次性软件开发费用。
