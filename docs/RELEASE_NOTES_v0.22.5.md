# H618 报告网关 v0.22.5

## 打印流采集

- 打印任务结束判定改为协议边界优先、空闲超时兜底。
- 支持 PJL、PCL、PJL 封装的 PCL XL、PostScript 和 PDF 常见结束标志。
- PCL 二进制数据长度会被跟踪，避免栅格数据中的相同字节被误判为 UEL。
- 捕获线程与 GhostPCL/Ghostscript 转换线程解耦，转换期间持续读取 USB 打印流。
- PRN 使用 `.part` 原子完成，服务重启可恢复未完成或待转换任务。

## 时间分析

- 每个新打印任务记录首字节、末字节、边界确认、接收耗时和转换耗时。
- 模拟打印页面显示结束依据、接收耗时、转换状态和转换耗时。
- 原“任务结束等待”改为“未知/异常打印流兜底等待”，旧配置保持不变。

## 升级说明

- 目标平台：`linux-arm64`
- 应用编码：`linux`
- 支持从 `v0.22.0` 至 `v0.22.4` 原子升级。
- 不重新转换已有 PRN，不覆盖现场配置和报告数据。
- 本次升级不需要重新绑定 USB Gadget 或重启 CUPS。
