# H618 报告网关 v0.21.2 测试更新

本版本用于验证 K2B 从 `0.21.1` 在线升级到 `0.21.2` 的完整流程。

## 修复

- 修复停止网页或采集服务超过 60 秒时，升级代理异常退出并导致板端管理页面无法访问的问题。
- 服务停止等待时间提高到 120 秒，以覆盖 systemd 的正常停止窗口。
- 安装或回滚任一步骤失败时，自动恢复当前应用链接并重新启动网页与采集服务。
- 将底层命令超时转换为可读的升级错误，便于板端页面和日志定位。

## 升级边界

- 仅允许从 `0.21.1` 升级。
- 不覆盖 `/etc/gadget-msc-printer/` 和 `/var/lib/gadget-msc-printer/`。
- 不重新绑定 USB Gadget，不重启 CUPS。
- 使用 Ed25519 正式签名，板端必须通过签名和 SHA-256 校验后才能安装。
