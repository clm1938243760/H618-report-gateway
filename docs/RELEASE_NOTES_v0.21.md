# H618 报告网关 v0.21

发布日期：2026-08-06

## 新增

- 板端在线升级代理：设备主动签到、一次性配对码、独立设备令牌、指数退避和本机安装策略。
- Ed25519 签名 `.jvpkg` 包：哈希、兼容版本、架构、路径安全和原子切换校验。
- Windows 升级中心：局域网 HTTPS 管理端、中心本机设备 API、发布包、设备/分组下发和审计记录。
- 管理页面新增“软件升级”：配对、检查、下载、安装、回滚和本机/远程安装策略。
- 管理页面新增“实体打印驱动”：DEB、PPD 和归档驱动的上传分析、风险提示、安装与 CUPS 备份回滚。
- 中心签名打印驱动包支持；未签名或含未审核 root 安装脚本的中心驱动会被拒绝。

## 安全与可靠性

- 更新代理仅监听 `127.0.0.1:8765`，浏览器经既有 HTTPS 会话和 CSRF 校验访问。
- 应用版本与现场配置/报告数据分离，安装失败或健康检查失败自动恢复上一版本。
- 下载任务成功后立即回报状态，中心不会重复下发已下载包。
- SQLite 连接在 Windows 升级中心中显式关闭，避免维护时文件锁残留。
- 驱动归档拒绝路径穿越、链接、设备文件和超过限制的解压内容。

## 验证

- Python 单元测试：86 项执行，83 项通过；本机缺少 OpenSSL 的签名测试及两个需要 Linux
  目录符号链接权限的原子切换测试已跳过。
- `compileall`：通过。
- Vue 生产构建：通过。
- KICKPI K2B 灰度板：已从 `0.1.0` 部署到 `0.21.0`；`gadget-mode`、
  `gadget-collector`、`gadget-web`、`jvlei-updater`、`cups` 均为 `active`，HTTPS
  健康接口、USB Gadget 和更新代理本机监听验证通过。
