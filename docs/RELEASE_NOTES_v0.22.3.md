# H618 报告网关 v0.22.3

## 网络配置

- 有线网络和 Wi-Fi 的子网前缀改为可输入、可搜索的下拉选择器。
- 支持通过 CIDR 数字、`/24` 形式或子网掩码快速匹配选项。
- 常用的 `/24`、`/16`、`/8` 等前缀优先显示，保存前统一校验并标准化。

## 升级说明

- 目标平台：`linux-arm64`
- 应用编码：`linux`
- 支持从 `v0.22.0`、`v0.22.1` 和 `v0.22.2` 原子升级。
- 不覆盖 `/etc/gadget-msc-printer` 和 `/var/lib/gadget-msc-printer`。
