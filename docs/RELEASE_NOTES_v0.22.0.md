# H618 报告网关 v0.22.0

## 在线升级

- 停用 Windows 升级中心、配对码、设备令牌和 `.jvpkg` 流程。
- 接入公司 `report-terminal-info`、`check`、`report` 和 `rollback-report` 接口。
- 使用 `appCode=linux`、`platform=linux-arm64`，动态上报实际联网 IP/MAC。
- 开机上报终端并检查一次；网页支持手动检查、下载、安装和回滚。
- 公司策略 `autoUpgrade=true` 自动执行，关闭时等待现场确认。
- 临时链接失效后重新调用 `/check` 刷新一次，不依赖需要 JWT 的包链接接口。

## 包安全和安装

- 公司 ZIP 固定为 `manifest.json + payload.tar.gz`。
- 校验公司响应包大小、ZIP CRC、payload SHA-256、文件数量、平台和兼容版本。
- 拒绝路径穿越、重复路径、链接、设备文件、FIFO 和异常解压体积。
- 安装前等待活动报告并备份现场配置，原子切换应用和升级代理。
- 健康检查失败时自动恢复上一版，并向公司接口上报升级和回滚结果。
- 上报失败进入本地待发送队列，不回滚健康的新版本。

## 管理页面

- 升级页显示公司服务地址、实际联网接口、IP/MAC、版本 ID、策略和任务进度。
- 升级页可维护医院、院区和科室标识，保存后立即同步公司终端信息；医院编码与报告上传共用。
- 删除配对、代理编号和本机安装策略选项。
- 安装和回滚改为后台任务，避免网页服务重启导致请求被误判为失败。
- 页面明确提示当前测试 ZIP 尚未启用数字签名。

## 保持不变

- USB Gadget 四种模式、报告采集、转换、上传、CUPS 实体打印和本地驱动上传保持不变。
- `/etc/gadget-msc-printer` 与 `/var/lib/gadget-msc-printer` 不由升级包覆盖。
- 本版本不升级内核、U-Boot、设备树或 Armbian 系统镜像。
